## 1. 架构演进：从外部静态孤岛到现代化原生前端

在早期阶段，Web 3D 粒子视觉交互往往被封装在独立、庞大的单文件 HTML 中（如 `public/gesture-interactive.html`）。这类遗留架构在现代全栈生产环境中面临四大致命瓶颈：

1. **CDN 脚本级联故障与冷启动延迟**：过度依赖外部公共 CDN（cdnjs/jsdelivr），网络波动或跨域策略变更易导致首屏阻塞或白屏；
2. **移动端触控缺失与上下文割裂**：传统的鼠标事件在移动设备上缺乏单指视角漫游、双指缩放（Pinch-to-zoom）与引力触控反馈；
3. **音频上下文自动播放限制（Autoplay Policy）**：移动端主流 Webkit/Blink 引擎要求音频必须在明确的用户交互事件（User Gesture）中初始化；
4. **单体生命周期无法被现代路由接管**：无法与 Next.js 页面级元数据管理、组件状态持久化及统一暗夜/玻璃拟态主题体系协同。

全新重构的原生架构将 Three.js 与 Web Audio API 深度封装为 React 原生客户端组件，由 Next.js 路由系统统一纳管，并在移动端自动执行 DPR 钳位与粒子密度动态调优。

```
[ 用户端设备侦测 ] 
       │
       ├── 桌面端 (高算力) ──> 12,000+ 粒子流 ──> 开启抗锯齿 ──> 摄像头/鼠标双通道
       └── 移动端 (低功耗) ──> 5,500 粒子流  ──> 限制 DPR≤1.5 ──> 全手势触控引擎
```

## 2. 粒子几何形态场（Morphing Field）参数方程推导

系统支持在六种高维几何形态间无缝平滑形变。每个粒子 $i \in [0, N-1]$ 对应空间三维坐标 $(x_i, y_i, z_i)$。

### 2.1 3D 立体心形曲面（Quantum Heart）

心形由二维心形基底曲线在法向维度施加高斯厚度调制演化而来：

$$
\begin{aligned}
t &\sim \mathcal{U}(0, 2\pi), \quad u \sim \mathcal{U}\left(-\frac{\pi}{2}, \frac{\pi}{2}\right) \\
x_0(t) &= 16 \sin^3(t) \\
y_0(t) &= 13 \cos(t) - 5 \cos(2t) - 2 \cos(3t) - \cos(4t) \\
z_0(t, u) &= \cos(u) \cdot (12 - 0.4 |x_0(t)|) \cdot \sin(u)
\end{aligned}
$$

### 2.2 双螺旋结构（Double Helix DNA）

模拟互补碱基链的几何双螺旋拓扑分布。链索引 $s \in \{0, \pi\}$，主链沿 Y 轴展开：

$$
\begin{cases}
\theta_i = \left(\frac{i}{N}\right) \cdot 18\pi \\
x_i = R \cos(\theta_i + s) + \epsilon_x \\
z_i = R \sin(\theta_i + s) + \epsilon_z \\
y_i = \left(\frac{i}{N} - 0.5\right) \cdot H
\end{cases}
$$

其中 $15\%$ 的粒子被抽取作为连接两条主链的氢键与碱基梯级（Rungs），通过线性插值形成立体链桥：

```ts
// 碱基对插值计算示例
const lerp = Math.random();
x = (Math.cos(t) * radius * lerp) + (Math.cos(t + Math.PI) * radius * (1 - lerp));
z = (Math.sin(t) * radius * lerp) + (Math.sin(t + Math.PI) * radius * (1 - lerp));
y = ((i / count) - 0.5) * height;
```

## 3. 实时引力物理场与弹簧阻尼插值系统

为避免粒子在形态切换或外力扰动时产生机械生硬的瞬变，本系统建立了实时弹簧阻尼插值模型（Spring-Damper Lerp）。

### 3.1 坐标更新微分方程

设第 $i$ 个粒子的当前渲染坐标为 $\mathbf{p}_i(t)$，目标几何形态坐标为 $\mathbf{p}^*_i$，触控/手势吸引子坐标为 $\mathbf{a}$。粒子位移更新规律如下：

$$
\mathbf{p}_i(t + \Delta t) = \mathbf{p}_i(t) + \alpha \left(\mathbf{p}^*_i + \mathbf{F}_{\text{attractor}}(\mathbf{p}_i, \mathbf{a}) + \mathbf{F}_{\text{audio}} - \mathbf{p}_i(t)\right)
$$

其中 $\alpha \in [0.05, 0.08]$ 为弹性阻尼系数。引力场 $\mathbf{F}_{\text{attractor}}$ 遵循受限二次衰减法则：

$$
\mathbf{F}_{\text{attractor}}(\mathbf{p}, \mathbf{a}) = 
\begin{cases}
\left(1 - \frac{\|\mathbf{a} - \mathbf{p}\|^2}{R_{\text{max}}^2}\right) \cdot k \cdot (\mathbf{a} - \mathbf{p}), & \text{当 } \|\mathbf{a} - \mathbf{p}\| < R_{\text{max}} \\
\mathbf{0}, & \text{其他}
\end{cases}
$$

## 4. Web Audio 频域特征提取与粒子共振联动

通过 Web Audio API 的 `AnalyserNode` 进行离散傅里叶变换（FFT）：

```ts
const analyser = audioContext.createAnalyser();
analyser.fftSize = 128; // 获取 64 个频段的分辨率
const freqData = new Uint8Array(analyser.frequencyBinCount);
analyser.getByteFrequencyData(freqData);

// 提取低频能量 (Kick & Bass: 0 ~ 8 频段)
const bassEnergy = freqData.slice(0, 8).reduce((a, b) => a + b, 0) / (8 * 255);

// 提取高频能量 (Hi-hats & Sparkles: 16 ~ 32 频段)
const highEnergy = freqData.slice(16, 32).reduce((a, b) => a + b, 0) / (16 * 255);
```

- **低频能量驱动宏观心跳（Macro Scale）**：直接调制整体粒子系统的 `scale`，产生随节奏泵动的强劲呼吸感；
- **高频能量驱动微观扰动（Micro Jitter）**：为每个粒子坐标叠加高频正弦噪声，使粒子流在鼓点高潮时展现微波沸腾特效。

## 6. 验证与边缘用例测试

```js
import assert from "node:assert/strict";

// 测试引力场衰减函数在临界距离时的连续性
function computeAttractorForce(distSq, maxRadiusSq, factor = 1.5) {
  if (distSq >= maxRadiusSq || distSq <= 0) return 0;
  return (1 - distSq / maxRadiusSq) * factor;
}

const maxRadiusSq = 2500;
assert.equal(computeAttractorForce(0, maxRadiusSq), 0, "零距离无引力除以零");
assert.equal(computeAttractorForce(2500, maxRadiusSq), 0, "边界距离力应归零");
assert.ok(computeAttractorForce(100, maxRadiusSq) > computeAttractorForce(1000, maxRadiusSq), "近距引力必大于远距引力");
```
