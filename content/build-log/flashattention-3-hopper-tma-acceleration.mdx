## 从 IO 感知到硬件异步流水线 (Warp Specialization)

FlashAttention-1 与 FlashAttention-2 的核心贡献在于“IO 感知（IO-Awareness）”：通过分块计算（Tiling）与在线 Softmax 统计更新，避免将庞大的 $N \times N$ 注意力矩阵写入高延迟的 GPU HBM 显存。

然而在 NVIDIA Hopper（H100/H800）架构上，新的硬件瓶颈出现了：张量核心（Tensor Core）的计算吞吐爆发式增长，而传统的异步数据加载指令依然会占用计算 Warp 的执行周期。FlashAttention-3 的核心使命就是彻底实现**数据搬运与矩阵计算的完全硬件级重叠（Hardware Overlapping）**。

## 张量内存加速器 (TMA) 与 WGMMA 指令

FlashAttention-3 依托 Hopper 架构专属硬件原语：
1. **张量内存加速器 (TMA, Tensor Memory Accelerator)**：由专用硬件单元直接负责全局显存（Global Memory）到共享显存（Shared Memory）的多维张量异步拷贝，无需任何寄存器中转与 Warp 线程轮询；
2. **翘曲专业化 (Warp Specialization)**：显式划分负责搬运数据的 Producer Warp 与负责 GEMM 计算的 Consumer Warp，通过硬件屏障（mbarrier）实现零停顿的乒乓双缓冲（Ping-Pong Buffering）；
3. **低精度 FP8 块级量化**：支持 FP8 GEMM 计算，使单卡注意力计算吞吐接近 1.2 PFLOPS。

import assert from "node:assert/strict";
function onlineMax(prev, cur) {
  return Math.max(prev, cur);
}
assert.equal(onlineMax(1.5, 3.2), 3.2);
