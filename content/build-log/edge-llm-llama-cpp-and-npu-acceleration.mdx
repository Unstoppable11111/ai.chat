## 为什么端侧本地运行大模型正在爆发

虽然云端大模型算力强大，但数据隐私敏感（法务医疗、个人日记）、离线可用性、网络不稳定以及 API 计费成本，驱动着“端侧大模型（On-Device LLM）”的快速繁荣。

借助 **Llama.cpp** 和 **GGUF** 规范，如今在一部轻薄笔记本甚至手机上，即可顺畅运行 7B~14B 甚至 32B 大模型。

## GGUF 格式设计与零拷贝内存映射 (mmap)

端侧推理性能的核心秘诀涵盖：
1. **GGUF 单文件二进制封装**：统一将模型架构超参数、Tokenizer 词表、分层量化权重打包，彻底杜绝 PyTorch 复杂的运行时依赖；
2. **零拷贝 mmap 加载**：通过系统级 `mmap` 系统调用，将模型文件直接映射进虚拟内存空间，模型秒级加载启动，无需漫长读取与反序列化；
3. **硬件统一内存（Unified Memory）**：在 Apple Silicon（M 系列芯片）上，CPU 与 GPU 共享同一块极高带宽的物理统一内存，大模型无需在总线上反复拷贝张量，大幅降低推理功耗。

## GGUF 头部元数据解析轻量验证

```js
import assert from "node:assert/strict";
function isGGUF(magic) {
  return magic === "GGUF";
}
assert.equal(isGGUF("GGUF"), true);
assert.equal(isGGUF("BIN"), false);
```
