## 实际界面

![本站聊天页面的浏览器验证截图](/images/studio-chat-verified.png)

本站将公开内容和登录后工作台放在同一应用中，但使用不同的数据权限。公开文章可以被搜索与引用；持仓、报告、模拟记录和登录后的聊天历史绑定服务端解析出的用户身份。

## 内容发布与检索路径

Markdown 文件经过同步脚本全量写入 MySQL posts。列表、正文、metadata、sitemap 与检索读取同一套发布查询，草稿不出现在公开列表中。只有明确标记 ragReady 的内容进入聊天检索。

分块器使用 Markdown 语法树保留 H2/H3 层次、完整代码块和原文行号。每个引用携带正文哈希、文章路径和段落锚点。当前检索采用中文词法基线；没有将它包装成已经上线的向量或混合检索服务。

## 多用户隔离

密码采用加盐 scrypt 摘要。会话使用随机令牌，数据库保存令牌摘要和过期时间。查询、更新和删除持仓时均包含会话用户 ID，客户端传入的 userId 不决定数据归属。

模拟账户查看接口不交易、不写入历史。手动模拟记录通过事务保存，并使用按用户区分的幂等键避免重复提交。它是参考价记账实验，不是券商交易连接。

## 验证方式与边界

已在独立 MySQL 测试库中建立两个用户，验证彼此不能读取或修改持仓、聊天历史及报告。浏览器验证覆盖 390、1024 和 1440 像素宽度；这些检查不等于所有设备上的完整兼容性认证。

文章中的 JavaScript 示例由 Node 测试执行。检索测试覆盖 12 个技术主题，但还需要来自真实用户的改写问题与无答案样本，才能评估更广泛的召回质量。
